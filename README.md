Kestrel Yard — a three.js tactical FPS: plant/defuse rounds on a container yard at dusk, bots that hold, rotate and defuse, a buy menu between rounds, and full gunplay with headshots, recoil, spread and crouch.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 to play.
